# BF Lernakademie v2
Node.js 20+. Install: npm install; start: npm start.
Railway Volume mount path: /data.
Environment variables: DATA_DIR=/data, ADMIN_USERNAME=ausbilder, ADMIN_PASSWORD=your strong password (8+ characters), SESSION_SECRET=long random secret, NODE_ENV=production.
Features: accounts and password hashing, SQLite persistent data, question bank by topic, saved test results and progress, study groups and chat, instructor question authoring, uploads (PDF/DOC/DOCX/PPT/PPTX/TXT/MD, 20 MB).
Included questions are a starter set, not an official complete BF examination bank. Requirements vary by city/state; verify and expand with current official training material.
